Overview

HomeDecor AR App is an augmented reality furniture visualization tool that allows users to preview furniture in real-world environments with accurate scale and alignment.

Features
 1. Real-world furniture placement with correct scaling
 2. Spatial alignment on detected surfaces
 3. Customization options for materials, colors, and textures
 4. Optimized performance for mobile devices

Tech Stack
 1. Unity
 2. AR Foundation
 3. ARCore
 4. C#

Setup
 1. Open the project in Unity
 2. Install AR Foundation and required AR packages
 3. Select mobile build platform
 4. Build and run on a supported device
